# Controls

## Movement

| Input | Action |
| --- | --- |
| `W` `A` `S` `D` | Move (camera-relative) |
| Mouse click on ground | Move to point |
| Mouse drag | Rotate camera |
| Mouse wheel | Zoom in/out |
| `Shift` | Dodge roll |

## Combat

| Input | Action |
| --- | --- |
| Left click an enemy | Target and attack |
| `Space` | Attack selected target (or nearest in range) |
| `1` .. `0` | Use the matching action-bar ability |
| Click an action-bar slot | Use that ability |

## Interaction

| Input | Action |
| --- | --- |
| `E` | Interact with the nearest NPC, resource node, or ground loot |
| Left click an NPC | Talk |
| Left click ground loot | Pick up / move toward it |

## Interface

| Input | Action |
| --- | --- |
| `I` | Toggle inventory and equipment |
| `K` | Toggle skills and abilities |
| `J` | Toggle quests |
| `C` | Toggle crafting |
| `O` | Toggle settings |
| `Esc` | Close panels and dialogue |
| `Enter` or `/` | Focus the chat input |
| `Enter` (while typing) | Send the chat message |

## Inventory

- Left click an item to use it (consumable) or equip it (equipment).
- Right click an item to drop one.
- Click an equipped item slot to unequip.

## Settings

The settings panel controls graphics quality, draw distance, pixel size, audio
volume, camera Y inversion, and camera shake. These affect rendering and audio
only; gameplay is identical online and offline.
